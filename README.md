# Sprint 4 Task --- Source-to-Target Data Mapping

This repository contains the source-to-target data mapping artifact
created for Sprint 4 Task 1.

## Data Flow

The mapping documents the complete data flow across the following
layers:

**Source → Landing → DWH → DM**

The workbook is divided into three mapping sheets:

-   `01_SRC_to_LND` --- Source to Landing mapping
-   `02_LND_to_DWH` --- Landing to Data Warehouse mapping
-   `03_DWH_to_DM` --- Data Warehouse to Data Mart mapping

## Mapping Contents

The mapping includes:

-   Schema names
-   Table names
-   Column names
-   Data types
-   NULL / NOT NULL definitions
-   Default values
-   Primary and foreign keys
-   Transformation expressions
-   Join and lookup logic
-   Business rules and mapping comments
